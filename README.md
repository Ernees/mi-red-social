# 🌐 Mi Red Social

¡Bienvenido a **Mi Red Social**!  
Este proyecto es una aplicación **fullstack** desarrollada con **Angular** en el frontend y **Nest.js + MongoDB** en el backend.  
Permite a los usuarios registrarse, iniciar sesión, crear publicaciones y conectarse entre sí.

---

## ✨ Funcionalidades Principales

- 👤 **Autenticación de Usuarios** — Registro e inicio de sesión con validación segura mediante **JWT**.
- 📝 **Publicaciones** — Creación, edición y eliminación de posts.
- ❤️ **Interacciones** — Dar "me gusta" a publicaciones de otros usuarios.
- 🔒 **Protección de Rutas** — Middlewares personalizados para controlar el acceso.
- 📱 **Interfaz Responsiva** — Frontend en Angular optimizado para distintos dispositivos.

---

## 🛠️ Tecnologías Utilizadas

**Frontend:**
- Angular  
- TypeScript  
- HTML / CSS  

**Backend:**
- Nest.js (framework sobre Node.js)  
- MongoDB con Mongoose  
- JWT para autenticación  

**Herramientas:**
- Git & GitHub  
- Postman (testeo de APIs)  
- Docker (configuración básica para el backend)

## 🚀 Instalación y Uso Local

1. Cloná el repositorio:

```bash
git clone https://github.com/Ernees/mi-red-social.git
```
2. Entrá a la carpeta del backend:
```bash
cd backend
npm install
npm run start
```
3. Entrá a la carpeta del frontend:
```bash
cd frontend
npm install
ng serve
```
4. Abrí http://localhost:4200 en tu navegador.
